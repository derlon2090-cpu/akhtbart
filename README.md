# اختبار عباقرة الكيمياء التقنية

اختبار عربي متجاوب من 10 أسئلة في أساسيات الكيمياء، مدته 10 دقائق، مع اختيار الصف والشعبة وتقرير PDF/CSV ولوحة إدارة.

## المسارات

- الطلاب: `/students`
- الإدارة: `/admin`
- واجهة API: `/api/attempts`

## إعداد Vercel

1. اربط المشروع بقاعدة Neon PostgreSQL وأنشئ متغير البيئة `DATABASE_URL` في Vercel.
2. أنشئ `ADMIN_PIN` قويًا في Vercel Environment Variables. لا تضع الرقم السري داخل ملفات الواجهة أو المستودع.
3. أعد النشر. تنشئ واجهة API جدولي المحاولات والزيارات تلقائيًا عند أول طلب.
4. تحقّق من مساري `/students` و`/admin`، ثم اختبر تسليم محاولة تجريبية واحدة.

يستخدم جدول المحاولات البريد الإلكتروني بصيغة موحدة كمفتاح فريد؛ الإدخال الأول يُحفظ، وأي تسليم لاحق للبريد نفسه يُرفض مع الاحتفاظ بالأول. تحفظ قاعدة البيانات الاسم والصف والشعبة والدرجة وزمن الحل والبريد. يُجمع عدد الزيارات بمعرّف جلسة مستعار.

## قواعد الاسم والبريد

يتحقق النظام من تنسيق البريد فقط؛ لا يثبت ملكيته أو انتماءه للمدرسة دون رمز تحقق، ولم يُفترض نطاق مدرسي بعينه. يرفض الاسم الناقص والرموز والتكرارات النصية الواضحة، لكن لا يستطيع ضمان أن الاسم حقيقي أو اكتشاف كل الكلمات العشوائية من دون مصدر أسماء معتمد.

## ملاحظات

- يلزم اتصال قاعدة البيانات لتسجيل المحاولات أو التحقق من البريد. عند تعذر الاتصال لا تظهر النتيجة على أنها محفوظة.
- منع النسخ في الواجهة يظل قيدًا بصريًا ولا يمنع التصوير أو تجاوز المتصفح.
- التقرير PDF يُنشأ عبر نافذة الطباعة، ويمكن اختيار «حفظ كملف PDF».
- لا تُرسل بيانات الطلاب إلى Neon قبل إعداد اتصال قاعدة البيانات الذي تختاره الجهة المشرفة.
